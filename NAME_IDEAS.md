# Game Name Ideas

Working notes for renaming the game away from "Scoundrel." The core problem
with "Scoundrel" is that it paints the protagonist as a villain, when the
fiction is a nameless amnesiac who wakes in a stone chamber, descends alone,
and reaches daylight at the bottom. A new name should describe the journey (the
sympathetic part), not brand the character as a crook.

Game vocab available to work with: Descent, Trial, Sanctuary, Sigil (seven to
escape), Boon, Forge ("the coals never died"), Room, the Hold, Flee. Deck
facts: hearts = life, diamonds = weapons, clubs/spades = monsters, the monster
ladder climbs toward the Ace (rank 14), red face cards removed.

Current favorites (as of pausing): **Dawnward**, plus the card-phrase cluster
**The Last Hand**, **Dealt in the Dark**, **Cut to the Deep**. Nothing
pressure-tested for collisions yet except the first batch (see bottom).

## Pressure-test notes (collisions checked so far)

Only Round 1 has been checked against existing games:

- **Emberlight**: disqualified. An exact-name, same-genre roguelike dungeon
  crawler already exists on Steam (Quarter Onion Games, 2019).
- **Delve**: great fit, terrible discoverability. Both "Delve" and "Delver"
  exist on Steam, and "delve" is a generic genre verb.
- **The Descent**: perfect theme, heavy cliche. Many roguelike deckbuilders use
  "Descent"; Fantasy Flight's tabletop "Descent" is a trademark concern.
- **Vigil**: strong tone, but the bare word is taken (horror game, metroidvania).
  No roguelike-card owner, so a subtitle could rescue it.
- **Daybreak**: cleanest inside the roguelike niche (no collision found), but
  Matt Leacock's "Daybreak" board game and Daybreak Game Company are notable
  namesakes outside it.

Everything from Round 2 onward is unchecked. Next step when we resume: pressure-
test the shortlist (Dawnward, the card-phrase cluster, Descent in Spades, Hold
or Fold, Trial and Descent, Spadefall).
